# Demonstration

Recorded locally on 20 October 2026 with the actual pinned Qwen3 model and
explicitly synthetic notes. No API mocks were installed for this run.

Watch [walkthrough.mp4](walkthrough.mp4) or the original
[walkthrough.webm](walkthrough.webm). The recording shows generating an action
list, reviewing source evidence, editing an action, marking it done, exporting
Markdown, and the mobile layout.

![Loose Ends with four source-backed draft actions](desktop.png)

The [reviewed desktop](desktop-reviewed.png) and [mobile](mobile.png) captures
show a human edit and completion state. [action-list.md](action-list.md) is the
actual export. Demo results and source hashes are in
[browser-real-demo.json](../evidence/browser-real-demo.json).

The footage is a short workflow demonstration. It is not a claim of measured
time savings, comprehensive model accuracy, or contest credit.
