# Demonstration

## October 22 release

Watch [release-walkthrough.mp4](release-walkthrough.mp4), recorded with actual
local Qwen inference on synthetic project-handoff notes. It shows three expected
actions, one rejected proposal, the complete checklist condition, editing,
completion and a Markdown download. The video is about 70 seconds and contains
the full model wait, without cuts or retiming.

See the [desktop](release-desktop.png), [edited desktop](release-desktop-reviewed.png),
[mobile](release-mobile.png), [actual export](release-action-list.md),
[recording details](release-notes.md), and
[browser receipt](../evidence/submission-browser.json).
This local-notes demonstration does not establish hosted or long-meeting accuracy.

## Historical October 20 demonstration

Recorded locally on 20 October 2026 with the actual pinned Qwen3 model and
explicitly synthetic notes. No API mocks were installed for this run.

Watch [walkthrough.mp4](walkthrough.mp4). The recording shows generating an action
list, reviewing source evidence, editing an action, marking it done, exporting
Markdown, and the mobile layout.

![Loose Ends with four source-backed draft actions](desktop.png)

See the [empty workspace](empty.png), or the human edit and completion state in
the [reviewed desktop](desktop-reviewed.png) and [mobile action list](mobile.png).
[action-list.md](action-list.md) is the actual export with its terminal blank line
removed for repository formatting. The receipt retains the exact downloaded
text. Demo results and source hashes are in
[browser-real-demo.json](../evidence/browser-real-demo.json).

The footage is a short workflow demonstration. It is not a claim of measured
time savings, comprehensive model accuracy, or contest credit.

This is the unmodified native browser recording. Its encoded duration differs
from the capture wall time; use the separately measured API duration in the
receipt rather than the video's running time for latency.
The [initial design's recording](archive/initial-walkthrough.webm) is preserved
as historical evidence, and does not show the current UI.
